# Python Simple Calculator

A simple Python calculator that performs five basic mathematical operations: addition, subtraction, multiplication, division, and average.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Average of two numbers
- Basic input validation for division by zero

## Technologies
- Python 3

## How to Run
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run:

   ```bash
   python calculator.py
   ```

## Purpose
This project was created to practice Python fundamentals, user input, conditional statements, and arithmetic operations.
